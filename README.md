## 📌 Executive Summary

NetSage AI provides a systematic approach to diagnosing, fixing, and verifying network configuration failures across Cisco Packet Tracer enterprise campus topologies.

- **Factual Diagnostic Dataset (`cases.csv`)**: 20 comprehensive fault scenarios covering OSI Layers 1 through 7.
- **Live Executed Evidence (`evidence/`)**: 12 active fault scenarios + baseline state executed live in Cisco Packet Tracer with 36 captured screenshots stored using clean relative paths (`evidence/CASE-001/` through `evidence/CASE-012/`).
- **Reference & AI Prompting Test-bench (`CASE-013` to `CASE-020`)**: 8 extended reference scenarios for LLM automated diagnostic benchmarking.
- **Structured AI System Prompt (`diagnose_prompt.md`)**: Instructs LLMs to return strict JSON responses containing `root_cause`, `confidence`, `evidence`, `next_command`, and `fix_steps`.
- **Deterministic Python Rule Checker (`rule_checker.py`)**: Evaluates 10 deterministic failure rules (duplicate IP, subnet mismatch, gateway mismatch, admin down, missing VLAN, etc.).
- **Responsible AI Audit (`responsible_ai_log.csv`)**: Records human engineer reviews, tracking Accepted, Edited, and Rejected decisions.
- **Analytics Dashboard (`dashboard/`)**: Features an interactive HTML dashboard, Excel workbook (`dashboard.xlsx`), static PNG charts, and CSV metrics.

## 🧠 AI Diagnostic Engine (`diagnose_prompt.md`)

The AI Diagnostic Engine parses textual network evidence (command outputs, IP configurations, syslog messages) and outputs a structured JSON analysis strictly adhering to the schema below:

```json
{
  "root_cause": "Specific, unambiguous single sentence explaining the exact failure point.",
  "confidence": "High | Medium | Low",
  "evidence": "Factual command output lines or configuration values supporting the root cause.",
  "next_command": "Recommended Cisco IOS or host OS CLI command to run next if confidence is limited.",
  "fix_steps": "Numbered exact step-by-step CLI commands or GUI actions to resolve the fault."
}
```

## ⚙️ Deterministic Python Rule Checker (`rule_checker.py`)

The rule checker validates `cases.csv` using 10 deterministic failure rules:

```bash
# Run rule checker script
python rule_checker.py > rule_checker_output.txt
```

Output is saved to [`rule_checker_output.txt`](rule_checker_output.txt), verifying:
1. Duplicate IP address collision
2. Subnet mask mismatch
3. Default gateway misconfiguration
4. Router / Switch interface shutdown
5. Missing VLAN from trunk allowed list
6. DHCP pool default-router mismatch
7. ACL ICMP traffic drop
8. Port security err-disabled violation
9. Duplex mismatch late collisions
10. Router subinterface encapsulation mismatch

## 🤝 Responsible AI Review Audit (`responsible_ai_log.csv`)

Human-in-the-loop review was conducted for every AI output:
- **Accepted**: AI diagnosis was 100% accurate and fix steps were concise.
- **Edited**: Human auditor refined CLI commands to prevent unnecessary disruptions (e.g. adding explicit `no access-list` removal).
- **Rejected**: AI hallucinated root cause assumptions; human engineer corrected diagnosis.
